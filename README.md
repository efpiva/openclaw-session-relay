# openclaw-session-relay

A planned OpenClaw plugin for sending a text task to another session and returning a checked reply. The host decides whether the task may run and whether the reply may leave the receiving session. Routing a message does not grant permission to act.

## Status

This repository currently contains project documentation and the license only. There is no installable release or supported npm install command yet.
